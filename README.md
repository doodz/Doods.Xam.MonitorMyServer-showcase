# MonitorMyServer

MonitorMyServer is an Android companion for checking and managing self-hosted servers. Connect over SSH, use OpenMediaVault RPC, or access Synology through its CGI interface.

**[Visit the project website](https://doodz.github.io/Doods.Xam.MonitorMyServer-showcase/)** · **[Get it on Google Play](https://play.google.com/store/apps/details?id=com.doods.monitormyserver)**

## What you can do

- Check system information, disk space, filesystems and RAID storage.
- View running processes and system logs.
- Check for updates and manage server tasks.
- Connect over SSH and run commands.
- Use OpenMediaVault RPC over HTTP or SSH, or Synology CGI over HTTP.

Some operations may require administrator or root privileges on the server.
